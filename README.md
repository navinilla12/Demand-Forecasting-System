# Demand Forecasting & Revenue Trend Prediction System

## Overview
This project builds a time-series forecasting model to predict demand trends using historical passenger data.

## Features
- Time series forecasting using ARIMA
- Seasonal trend modeling
- Forecast evaluation
- Visualization of predictions

## Tech Stack
Python, Pandas, Statsmodels, Matplotlib

## Workflow
1. Load time-series dataset
2. Split into train/test
3. Fit ARIMA model
4. Forecast future demand
5. Evaluate using RMSE

## Output
- Forecasted demand values
- Trend visualization
- Error metrics

## Use Case
Hospitality demand forecasting, airline booking prediction, revenue planning
